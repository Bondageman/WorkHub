# 🧭 Job Search Platform

This repository contains the source code for a **dynamic job search platform**, built to streamline the connection between talented professionals and prospective employers.  
The application provides a comprehensive suite of tools for both **candidates** seeking new opportunities and **companies** looking to hire top talent.

---

## 💡 Core Concept

The platform is designed as a **two-sided marketplace**:

### 👩‍💼 For Candidates
- Create a **personal profile** and build a resume by linking a **Google Docs** file — allowing easy updates and clean presentation.  
- Browse job listings using a **powerful search** with filters for:
  - Location  
  - Employment type  
  - Salary range  
- Apply to positions directly and manage all interactions within a **personal dashboard**.

### 🏢 For Employers
- Post detailed **job vacancies** and manage incoming applications.  
- **Search for qualified candidates** using built-in filters.  
- Communicate via an **integrated messaging system**.  
- Track the **hiring pipeline** and monitor each applicant’s progress.

### 🛡️ For Administrators
- Access a **dedicated admin panel** for full oversight.  
- Manage users, moderate content, and view **activity statistics** to maintain the platform’s integrity.

---

## ⚙️ Technical Implementation

The platform is built on a **modern and robust technology stack**:

### 🖥️ Front-End
- **React.js** for building a dynamic UI  
- **SCSS** styling with a **Flexbox layout**  
- Fully **responsive and adaptive** for desktop and mobile

### 🔧 Back-End
- **Node.js** + **Express.js** providing a secure REST API  
- Data handled in **JSON** format  
- **MySQL** database for user data, job listings, and applications  
- **bcrypt** used for password hashing and authentication security
